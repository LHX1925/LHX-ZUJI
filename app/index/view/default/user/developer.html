〇、快速开始（三步上手）

第一次使用？跟着下面三步，1 分钟内完成第一次接口调用：

  • 第一步：申请密钥 —— 在本页上方“申请专属密钥”处填写名称并提交，复制生成的 LHX- 开头密钥（仅完整显示一次，请妥善保管）。
  • 第二步：测试调用 —— 在下方“在线调试工具”中选择 user.info、粘贴密钥、点击发送，看到返回的账户信息即表示调用成功。
  • 第三步：阅读下文 —— 按需查阅接口总览与详细说明，把接口集成到你的网站、小程序或自动化脚本中。看不懂的名词先看“关键概念速查”。

一、接口地址

{$apiBase}

所有接口统一通过该地址访问，使用 action 参数区分不同功能，共支持三种调用方式：

# 方式一：GET 参数（查询类接口常用，例如用户信息、主机列表）
{$apiBase}?action=user.info

# 方式二：POST 表单 / JSON 体（写入类接口，例如提交工单、续费、签到）
curl -X POST -H "X-API-Key: 你的密钥" -d "action=ticket.submit&title=标题" "{$apiBase}"

# 方式三：URL 路径风格（action 写在路径中，与 ?action=xxx 等效）
{$apiBase}/user.info          （等同 action=user.info）

二、认证方式

除登录接口（login / qrlogin.create / qrlogin.status）外，每次请求必须携带你的专属密钥（密钥以 LHX- 开头），二选一：

# 方式一：请求头（推荐）
X-API-Key: 你的密钥

# 方式二：URL 或请求体参数
api_key=你的密钥

三、通用返回格式

所有接口统一返回 JSON 格式：

{
  "code": 1,        // 状态码：1=成功，-1=失败
  "msg": "ok",      // 提示信息（失败时为具体原因，如“API 密钥无效”）
  "data": { ... }   // 业务数据（对象或数组，仅成功时返回）
}
  • 成功示例：{"code":1,"msg":"ok","data":{...}}
  • 失败示例：{"code":-1,"msg":"API 密钥无效"}
  • 业务失败时 HTTP 状态码通常仍为 200，请以 code 字段判断成功与否，以 msg 读取失败原因。
安全限制：开发者 API 已覆盖官网全部用户功能：购买主机、余额充值、转让市场买卖、主机重置密码/暂停/恢复/删除、续费、升降级等均可通过接口完成。仅不支持修改账号与密码（user.password、user.account 被禁止）。

五、接口详细说明

以下按功能分类列出每个接口的请求参数与返回数据说明，可结合上方的接口总览表使用。

登录认证（无需密钥）

POST login — 账号密码登录

用账号（用户名或邮箱）+ 密码登录，成功后自动签发或复用你的 API 密钥。此接口无需携带 X-API-Key。

参数类型必填说明
accountstring是用户名或邮箱
passwordstring是登录密码
 
curl -X POST -d "account=你的账号&password=你的密码" "{$apiBase}/login"

返回示例（成功）：

{
  "code": 1,
  "msg": "登录成功",
  "data": {
    "api_key": "LHX-xxxxxxxx...",   // 后续调用接口时使用
    "userid": 1,
    "username": "demo",
    "nickname": "昵称",
    "email": "a@b.com",
    "balance": 0,
    "points": 0
  }
}

POST qrlogin.create — 生成扫码登录二维码

生成一次性扫码登录 token（5 分钟有效）。把返回的 qrurl 生成二维码，让用户在手机（已登录官网）上扫码确认，随后轮询 qrlogin.status 获取密钥。

curl -X POST "{$apiBase}/qrlogin.create"

返回示例：

{
  "code": 1,
  "token": "a1b2c3...",                              // 轮询时使用
  "qrurl": "https://你的站点/qrlogin/confirm?token=a1b2c3...",
  "expire": 300
}

POST qrlogin.status — 轮询扫码登录状态

轮询扫码结果：pending 未扫码、scanned 已扫码待确认、confirmed 已确认（此时返回 API 密钥）、expired 已失效。

参数类型必填说明
tokenstring是qrlogin.create 返回的 token
 
curl -X POST -d "token=a1b2c3..." "{$apiBase}/qrlogin.status"

返回示例（已确认）：

{
  "code": 1,
  "status": "confirmed",
  "msg": "登录成功",
  "data": {
    "api_key": "LHX-xxxxxxxx...",
    "userid": 1,
    "username": "demo"
  }
}

GET host.status — 实时主机状态

连接主机面板查询实时状态（空间、数据库、流量、续费时间、运行时间、网络与连接信息等），具体字段由面板接口返回。

参数类型必填说明
order_idint是主机订单ID（可通过 host.list 获取）
host_userstring否主机用户名，不填则使用订单默认用户名
 
// 请求
curl -H "X-API-Key: 你的密钥" "{$apiBase}?action=host.status&order_id=123"
// 返回（面板查询成功时 code=1，面板实时数据在 data.panel 中）
{
  "code": 1, "msg": "ok",
  "data": {
    "order_id": 123,          // 订单ID
    "host_user": "demo",       // 主机用户名
    "state": "1",             // 站内状态：0=待开通 1=正常 2=已暂停 3=已终止
    "state_text": "正常",
    "opened_at": "2026-08-24 10:00:00",   // 开通时间
    "expire_at": "2027-08-24 10:00:00",   // 到期时间
    "panel": {                // 面板实时数据（字段以面板实际返回为准）
      "space_used": "512MB",  // 已用空间
      "space_total": "2GB",   // 总空间
      "db_used": "1",         // 已用数据库数
      "db_total": "2",        // 数据库总数
      "run_time": "10天",      // 已运行时间
      "end_time": "2027-01-01" // 面板到期时间
    }
  }
}

// 面板查询失败时 code=-1，但 data 中仍返回站内主机状态（state/state_text 等），可据此判断主机在站内的状态

GET host.panel — 一键登录控制面板

返回主机控制面板的登录地址与表单字段，调用方按返回的 method 提交 fields 即可跳转登录面板（等效于官网“一键登录”）。别名：host.panel.login、host.login、host.sso。

参数类型必填说明
order_idint是主机订单ID
 
// 请求
curl -H "X-API-Key: 你的密钥" "{$apiBase}?action=host.panel&order_id=123"
// 返回
{
  "code": 1, "msg": "ok",
  "data": {
    "order_id": 123,
    "panel_type": "mnbt",     // 面板类型：mnbt=梦奈宝塔 easypanel=EasyPanel
    "login_url": "http://面板地址/user/idcdl.php?gn=logine",
    "method": "POST",          // 提交方式：POST 或 GET
    "fields": {               // 需要提交到 login_url 的表单字段
      "username": "demo",
      "password": "******"
    }
  }
}

九、说明

  • 接口返回均为 JSON，code=1 表示成功。
  • 接口已开启 CORS 跨域支持，可直接在任意网站的网页（HTML/JS）、PHP、Python 等客户端中调用，无需服务端代理。
  • POST 接口支持两种请求格式：application/x-www-form-urlencoded 表单（推荐）与 application/json JSON 体，参数名一致，两种均可。
  • 接口不限请求频率，但请勿滥用，否则管理员有权封禁账号或密钥。
  • 列表类接口默认 page=1、limit=20，可通过参数调整（limit 上限 50）。
  • 写操作（POST）建议通过 HTTPS 访问，避免密钥泄露。
  • 密钥泄露时请立即在“我的密钥”中停用或删除，并重新申请。
