宝塔面板 API 对接说明
  • 宝塔面板 → 设置 → API 接口 开启接口，复制 接口密钥（api_sk），并把本站服务器 IP 加入白名单。
  • 面板地址填写完整地址，如 http://1.2.3.4:8888 或 https://bt.example.com（结尾不要带斜杠）。
  • 调用接口：GetSystemTotal、GetNetWork、GetDiskInfo、GetCpuInfo、GetLoadAverage、GetMemInfo（并发请求 + 本地缓存）。
  • 接口文档：https://docs.bt.cn/api/system/
